# tg-tor-gate

Telegram bot that manages a local Tor daemon and exposes it as one fixed
**SOCKS5 proxy** whose **exit country you switch on demand** — straight from
Telegram, no config files to edit.

The list of available countries is not hardcoded: it's fetched live from the
Tor Project's [Onionoo](https://metrics.torproject.org/onionoo.html) API, so
it always matches the real, currently running exit relays.

> **Tested on:** Ubuntu 22.04 / 24.04 · Tor (system package) · Python 3.10+

---

## Features

| Command       | Description                                              |
| ------------- | --------------------------------------------------------- |
| `/status`     | Current exit country, SOCKS5 address, Tor status          |
| `/ip`         | Check the current exit IP and its country (live, via Tor) |
| `/locations`  | Paginated list of countries with active exit relays — tap to switch |
| `/random`     | Switch to a random exit country                           |
| `/any`        | Clear the country restriction (any exit worldwide)        |
| `/newip`      | New circuit, same country (fresh exit IP)                 |
| `/refresh`    | Force-refresh the live country list from Onionoo          |
| `/restart`    | Restart the Tor service                                   |
| `/help`       | Show all commands                                         |

All commands are also registered as the bot's **menu button** in Telegram, so
they're one tap away without typing.

Unauthorised users are **silently ignored** — no reply that would reveal the
bot exists.

---

## How it works

- One Tor daemon runs on the server with a fixed **SocksPort** (default
  `9050`) — this is the single proxy address every application should use.
  It never changes.
- The bot talks to Tor's **ControlPort** (via the [`stem`](https://stem.torproject.org/)
  library) to set `ExitNodes {country}` + `StrictNodes 1`, then signals
  `NEWNYM` to force a fresh circuit through that country.
- `/locations` queries `onionoo.torproject.org/details` for relays with the
  `Exit` flag that are currently `running`, counts them per country, and
  caches the result on disk (`LOCATIONS_CACHE_TTL_HOURS`, default 6h) so
  every button press doesn't hit the API.
- `/ip` reads the exit relay of the most recently built circuit directly
  from Tor's ControlPort (address + Tor's built-in GeoIP database) — not
  via an external HTTP request. External IP-lookup services rate-limit by
  source IP, and Tor exit IPs are shared by thousands of users, so they
  return 429s constantly; asking Tor directly avoids that entirely.

**Note on IP stability:** like any Tor exit, the IP within a country can
still rotate between circuits. `/newip` gives you a new IP in the same
country on demand; Tor may also rotate it on its own after a while.

## Install

One-line install (run as root):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ali934h/tg-tor-gate/main/install.sh)
```

The installer will:

1. Install `tor`, `python3`, `python3-venv`, and `git`
2. Configure Tor's `SocksPort` and a password-protected `ControlPort` in
   `/etc/tor/torrc` (existing torrc content is preserved — only a marked
   tg-tor-gate block is added/replaced)
3. Clone this repo to `/root/tg-tor-gate`
4. Create an isolated Python venv and install dependencies
5. Prompt for your bot token, allowed Telegram user IDs, SOCKS/Control
   ports (press Enter to accept the defaults), and an optional default
   exit country
6. Install and start a `systemd` service that auto-starts on reboot

```bash
journalctl -u tg-tor-gate -f      # live logs (Ctrl+C to stop)

bash /root/tg-tor-gate/update.sh      # pull latest code + restart
bash /root/tg-tor-gate/uninstall.sh   # remove everything
```

## Configuration

Settings live in `/root/tg-tor-gate/config.py` (chmod 600, not tracked by
git, generated by `install.sh`).

| Key                        | Default                                | Description                                            |
| --------------------------- | --------------------------------------- | -------------------------------------------------------- |
| `BOT_TOKEN`                | —                                      | Telegram bot token                                        |
| `ALLOWED_USERS`            | —                                      | List of numeric Telegram user IDs                         |
| `TOR_CONTROL_HOST/PORT`    | `127.0.0.1` / `9051`                   | Tor ControlPort                                            |
| `TOR_CONTROL_PASSWORD`     | (generated)                            | Matches `HashedControlPassword` in torrc                  |
| `TOR_SOCKS_HOST/PORT`      | `127.0.0.1` / `9050`                   | The fixed SOCKS5 proxy address                             |
| `DEFAULT_COUNTRY`          | `""`                                   | ISO code applied at install time; `""` = any exit          |
| `NEWNYM_COOLDOWN_SEC`      | `10`                                   | Throttle for `/newip` button spam                          |
| `CIRCUIT_BUILD_WAIT_SEC`   | `6`                                    | Wait after switching before reporting the new exit         |
| `ONIONOO_URL`              | `onionoo.torproject.org/details`       | Source for the live country list                           |
| `LOCATIONS_CACHE_TTL_HOURS`| `6`                                    | How long the country list is cached                        |
| `LOCATIONS_PER_PAGE`       | `8`                                    | Countries per page in `/locations`                         |
| `MIN_EXIT_RELAYS`          | `1`                                    | Hide countries with fewer active exit relays than this     |

`/ip` needs no config of its own — it reads straight from Tor's ControlPort.

## Using the proxy

Point any application at the SOCKS5 proxy:

```
socks5h://127.0.0.1:9050
```

(`socks5h` resolves DNS through Tor too — use it instead of plain `socks5`
where the client supports it.)

---

## Security notes

- `config.py` contains secrets and is in `.gitignore` — never commit it.
- Only user IDs in `ALLOWED_USERS` receive any response from the bot.
- The bot's systemd service runs as root (to control the `tor` systemd unit
  and read `torrc`). To use a dedicated user, adjust `User=` in the service
  file and grant it the necessary `sudo` rule for `systemctl restart tor`.
- The Tor `ControlPort` is bound to `127.0.0.1` only and password-protected;
  it is never exposed to the network.

## Project structure

```
bot.py              — Telegram bot (command handlers, inline keyboards, menu)
tor_control.py       — Tor ControlPort wrapper (stem): set exit country, NEWNYM
locations.py          — Live exit-country list from Onionoo, with disk cache
ip_check.py            — Check current exit IP/country through the Tor proxy
countries.py             — ISO country code → name, and flag emoji generator
config.example.py          — Template (install.sh generates config.py from this)
install.sh                   — One-line installer (Tor + venv + systemd)
update.sh                      — git pull + pip install + restart
uninstall.sh                     — Remove service, files, and torrc block
docs/                               — Developer & AI handoff documentation
```
